# Car value

Denna webapp räknar ut begagnat värdet av en bil. En bil minskar i värde varje år, och appens uträkningar är baserade på de.
Dessa värden är inte tagna ur luften utan är estimat som jag tagit fram genom att googla. De uppdateras inte automatiskt om förhållanden skulle ändras.

## Features
- Ange uppgifter på bilen som årsmodell, antal mil den gått osv
- Få förslag på årlig värdeminskning
- Kan användas för att få en tumvisning om vad bilen kan tänkas vara värd

## Purpose
Projektet är skapat för att utforska tanken bakom detta, för lärande och ska inte ses som något kommersiellt användbart
